Desert Batfly Task 13
Environmental Activity & Shelter Behavior
环境活动与房内避险生态
Specification revision: V2 / 2026-09-07
============================================================

STATUS
------
Formal implementation specification.
This document supersedes the shorter Task13 draft while preserving all previously approved design decisions.

Task13 is a realized-room environmental behavior layer.
It is NOT:
- a replacement for Task09 migration/refuge;
- a new social controller;
- a new persistent weather-memory system;
- a global flock commander;
- a second Fly locomotion controller;
- a wrapper around vanilla/default RoomSettings visual effects.

The implementation must integrate with the existing Task04 Injury, Task05A SocialBond/Grief, Task09 Colony Migration/Weather Refuge, Task10 Neutral Social Life, Task11 Threat Signature Memory and Task12 Observable Social Signal Network systems.

============================================================
1. PRIMARY PLAYER-FACING GOAL
============================================================

A player should be able to infer environmental change by watching Desert Batfly behavior before, during and after DryCycle weather.

The colony should look like many individuals reacting to a common environment through different Personality, Injury, Dehydration, experience and local geometry thresholds.
It must NOT look like one room controller flips every bat to the same state on the same frame.

Different weather families must produce different ecological strategies:
- LightRain: almost-normal life with weak moisture/rest effects.
- Fog: lower confidence and shorter activity range.
- DenseFog: strong navigation uncertainty, Home/Roost bias and possible temporary clear-room displacement.
- HeavyRain: classic covered-space sheltering.
- HeatWave: agitation/aggression rises first while shelter/exhaustion gradually rise behind it.
- IntenseHeat: broad damage-aggression permission coexists with strong Home/Roost/Burrow survival behavior.
- Sandstorm: species-specific early anticipation and Home retention; outward travel becomes undesirable.
- DeathSandstorm: strong pre-onset retreat, hard late survival, nearly no late long-distance travel.
- DeathRain: hard survival with Task09 owning pre-onset cross-room safety.

============================================================
2. HARD OWNERSHIP BOUNDARY: TASK09 VS TASK13
============================================================

Task09 exclusively owns cross-room ecology and travel:
- EmergencyRefuge selection;
- temporary weather displacement destination room;
- ReturnHome;
- ColonyMigration;
- permanent HomeColony changes;
- route planning / weighted room graph;
- LeaveRoom;
- abstract movement between rooms;
- long-term MigrationStress / shelter-history consequences;
- whether a cross-room route is still survivable.

Task13 owns only realized-room local behavior while the bat stays in the current room:
- environmental phase/context;
- local exposure avoidance;
- local shelter anchor choice;
- same-room Home/Hive retreat;
- Burrow pressure;
- Roost pressure and environmental Roost commitment;
- activity-radius changes;
- social/play/Harass weighting;
- weather-specific aggression permission;
- visibility/navigation uncertainty;
- staggered Recovery;
- bounded LocalShelterFailure evidence reported to Task09.

Task13 MUST NOT directly:
- choose another room;
- call LeaveRoom for its own purpose;
- create a migration batch;
- create ReturnHome intent;
- change HomeColony;
- run a second world-route search;
- continue pulling toward a local shelter anchor on a frame already owned by Task09 travel.

Hard ownership rule:
If Task09.TryDriveRealized() or equivalent current implementation reports that Task09 owns this frame, Task13 performs observation/debug bookkeeping only and does not modify localGoal or local behavior commitment.

============================================================
3. HARD WEATHER-SOURCE AUTHORITY
============================================================

Task13 may react ONLY to DryCycle-owned weather state.

Valid ecological sources:
- WeatherScheduleRuntime current schedule;
- active ScheduledWeatherEvent / candidate;
- WeatherSpatialRegistry authorization for region + room;
- DryCycle Weather event;
- DryCycle DangerType event;
- bounded DryCycle forecast information explicitly exposed through DesertBatflyWeatherEcology;
- future DryCycle local heat/wind/exposure provider explicitly associated with the currently active DryCycle event.

Invalid ecological sources:
- RoomSettings default Fog effect;
- RoomSettings visual fog amount;
- palette/effect values;
- shader fog amount;
- arbitrary vanilla Effect entries;
- visual post-processing state;
- another mod's effect unless it explicitly registers through a future DryCycle environmental-provider API.

Mandatory regression:
RoomSettings has strong Fog but DryCycle weather runtime reports no Fog -> Task13 remains Calm and does not reduce visibility/activity.

DryCycle DenseFog active -> Task13 DenseFog behavior is valid even if rendering happens to reuse RoomSettings fog infrastructure.

Implementation rule:
Task13 should consume a validated DryCycle environmental sample. Downstream behavior code should never independently inspect RoomSettings to infer weather.

============================================================
4. EXISTING WEATHER ECOLOGY SAMPLE IS THE WORLD-LEVEL INPUT
============================================================

Current DesertBatflyWeatherEcology already exposes approximately:
- HazardKind;
- HazardId;
- ActiveIntensity;
- ImmediateDanger;
- ShelterUrgency;
- MigrationStress;
- TravelExposure;
- TimeUntilDangerTicks;
- HasHazard / ForecastDanger / LethalNow.

Task13 must build local realized-room behavior from this semantic bridge instead of duplicating WeatherSchedule parsing in every individual.

Important distinction:
- MigrationStress is long-term Task09 evidence.
- Task13 WeatherMigrationSuppression is a CURRENT-ACTION gate saying "now is a bad time to start moving homes".

For Sandstorm it is valid that:
- the event contributes long-term habitat stress to Task09;
- Task13 simultaneously prevents a new migration batch from starting during strong preparation/active storm because travel is currently unsafe.

Do not zero Task09 evidence merely because Task13 suppresses current migration execution.

============================================================
6. SIX ENVIRONMENTAL PHASES
============================================================

Exactly these phases:
1) Calm
2) Advisory
3) Preparation
4) Sheltering
5) Acute
6) Recovery

This enum is environmental context, NOT DesertBatflyAI.Activity, NOT SocialRole and NOT persistent state.

Calm:
- Task13 nearly neutral;
- normal Task10, Harass, Task11, Task12, Roost and Fly behavior.

Advisory:
- bounded near-term environmental cue exists;
- subtle individual differences become visible;
- no mass shelter command.

Preparation:
- clearly visible contraction/reorganization;
- local Home/Roost/shelter pressure rises depending on profile;
- long roaming and nonessential behavior generally decline;
- Heat profiles may temporarily increase aggression despite entering Preparation.

Sheltering:
- local shelter/Home/Roost/Burrow dominates;
- neutral entertainment is rare;
- ordinary proactive Harass normally strongly suppressed except a heat-specific active aggression window when hard thermal survival has not won yet.

Acute:
- hard local survival;
- ordinary Personality cannot justify suicidal activity;
- Task09 owns any required cross-room travel;
- if current room is accepted as the survival room, Task13 owns local hard sheltering.

Recovery:
- hazard fell below active threshold;
- behavior returns gradually and individually;
- no same-frame whole-colony release.

============================================================
7. ROOM PHASE HYSTERESIS: FIRST TUNING BASELINE
============================================================

Do not use one threshold for both entry and exit.
Numbers below are initial tuning baselines, not immutable game truth.

General pressure P may be derived from weather profile + ShelterUrgency + ImmediateDanger + active intensity.

Suggested generic thresholds:
- Advisory enter: P >= 0.16 OR valid bounded forecast cue.
- Advisory exit: P < 0.08 and no relevant near forecast.
- Preparation enter: P >= 0.38.
- Preparation exit: P < 0.25.
- Sheltering enter: P >= 0.60.
- Sheltering exit: P < 0.42.
- Acute enter: HardSurvival profile OR ImmediateDanger >= ~0.78 with material active intensity.
- Acute exit: no longer lethal/hard AND P < ~0.55 for a minimum safe hold.

Weather profiles override/ceiling these values:
- LightRain alone: maximum Advisory.
- ordinary Fog: normally maximum Advisory/weak Preparation only if later tuning explicitly requires it; default V1 should stay Advisory.
- DenseFog: may reach Preparation/Sheltering from severe visibility loss but not "damage Acute" merely because vision is bad.
- IntenseHeat / DeathRain / DeathSandstorm can reach Acute.

All phase transitions require a minimum hold except immediate escalation into true Acute.

============================================================
8. INDIVIDUAL ENVIRONMENTAL COMMITMENT
============================================================

Each realized Desert Batfly may hold a short EnvironmentalCommitment.
Do NOT persist it.

Purpose:
- prevent anchor thrashing;
- prevent Calm/Preparation oscillation;
- prevent Roost/shelter abandonment every few frames;
- stagger group response.

Initial baseline:
- weak Advisory commitment: 60-140 ticks;
- Preparation: 120-240 ticks;
- Sheltering: 180-360 ticks;
- IntenseHeat/DeathSandstorm hard shelter commitment may be considerably longer;
- Recovery release delay: per-individual 80-600 ticks depending on weather severity/Personality/Injury.

Stable stagger input:
EntityID-derived deterministic offset, NOT UnityEngine.Random every frame.

Can interrupt commitment:
- death/unconscious;
- grabbed;
- immediate physical danger;
- Task09 taking travel ownership;
- severe shelter invalidation;
- direct forced game state such as shortcut/burrow transitions.

============================================================
9. NO FIXED FLIGHT HEIGHT / NO SECOND LOCOMOTION
============================================================

Rejected:
"bad weather -> fly lower"

Reasons:
- creates vertical correction loops;
- recreates the old boring up/down oscillation;
- makes little physical sense for Heat/Sandstorm;
- ignores real geometry.

Allowed:
- select/adjust localGoal toward a local safe pocket;
- reduce preferred activity radius;
- adjust nominal flight-speed intent if existing APIs support it;
- let original Fly/BatFlight physics move the creature.

Forbidden:
- Task13 direct writes to BodyChunk.vel;
- custom per-frame force controller;
- global fixed Y level;
- teleport-to-anchor;
- bypass collision/pathing;
- second world path planner.

============================================================
11. SHELTER ANCHOR SET
============================================================

Per realized room cache approximately 4-8 spatially separated anchors.
This is a soft target; very small rooms may legitimately have fewer.

Each anchor should expose approximately:
- AnchorId / stable room-local index;
- tile/position;
- GenericShelterQuality;
- RoofShielding;
- SideShielding;
- Enclosure;
- Shade/ThermalSuitability;
- RainSuitability;
- SandstormSuitability;
- Visibility/Familiarity value where applicable;
- nearby legal Roost compatibility;
- Hive/Burrow proximity;
- current Crowding;
- last validation tick.

Anchor generation:
1) low-frequency/coarse room sample;
2) score candidate terrain;
3) retain local maxima;
4) enforce minimum spatial separation;
5) cap anchor count;
6) cache until room invalidation/relevant geometry lifecycle.

Do not permanently assign anchors to bats.

============================================================
12. ANCHOR SCORING: IMPLEMENTATION BASELINE
============================================================

Use a profile-dependent score rather than one universal shelter score.

Conceptual individual score:
Score =
  HazardSuitability * W_shelter
+ Familiarity * W_familiarity
+ RoostCompatibility * W_roost
+ HiveBurrowAffinity * W_home
+ StableIndividualPreference * smallW
- NormalizedTravelDistance * W_distance
- Crowding * W_crowding
- OpenTravelExposure * W_openTravel
- InjuryTravelPenalty * W_injury.

Suggested generic first-pass weights:
- W_shelter ~ 0.45-0.60;
- W_distance ~ 0.10-0.20;
- W_crowding ~ 0.12-0.22;
- W_roost ~ 0.05-0.15 depending on profile;
- W_home ~ 0.05-0.18 depending on Sandstorm/Heat;
- W_injury increases for damaged individuals.

Weather-specific dominant geometry:
- LightRain/HeavyRain: roof/rain shielding.
- Heat: shade/thermal relief + roof where useful.
- Sandstorm: enclosure + side shielding + roof; future lee-side wind shelter.
- DenseFog: familiarity/nearby known geometry may outweigh generic enclosure.

Anchor switch margin:
Do not switch unless new score improves current by roughly 0.10-0.16 or current anchor becomes invalid/unsafe.

============================================================
13. SHELTER != ROOST
============================================================

Shelter = low environmental exposure.
Roost = legal Fly Chain/Hang anchor.

Possible combinations:
- high shelter, no Roost -> short-range sheltered flight;
- legal Roost, poor shelter -> bad environmental choice;
- high shelter + legal Roost -> preferred under sheltering weather.

Task10 remains sole owner of:
- RoostInvitation;
- ChainSocialization;
- FlyAI.ChainTile;
- platform underside legal support;
- chain-tail attachment;
- Roost reservation.

Task13 only modifies:
- Roost desire/multiplier;
- environmental preference for a Roost location;
- long environmental Roost commitment duration.

============================================================
15. PERSONALITY / BODY CONDITION MAPPING
============================================================

Nerve:
- high -> later nonlethal contraction, earlier Recovery, more likely to stay active during Heat agitation;
- low -> earlier contraction, later Recovery.

Conformity:
- never copies another bat's Task13 phase;
- indirectly strengthens group response because early Roosting creates existing Task12 RoostCall that Task10 can follow.

RoostAffinity:
- increases weather-driven Roost preference and commitment.

Temperament:
- delays ordinary activity suppression slightly;
- converts HeatAgitation into aggression strongly;
- tends to recover active behavior earlier.

Injury / PhysicalCapability / PostStunShock:
- earlier preparation;
- shorter preferred travel to shelter;
- higher open-space travel penalty;
- earlier Roost/Home/Burrow;
- slower Recovery;
- severe Injury strongly vetoes IntenseHeat damage aggression.

Dehydration:
- increases thermal shelter/exhaustion burden;
- shortens Heat aggression window;
- may create weak LightRain moisture incentive if truly rain-exposed.

Do not create new persistent HeatTolerance.

Derived HeatTolerance baseline may combine:
+ 0.35*Nerve
+ 0.35*PhysicalCapability
+ 0.15*Temperament
+ stable EntityID variance (~ +/-0.08)
- Injury penalty
- PostStunShock penalty
- Dehydration penalty.

Clamp 0..1 and keep realized/derived only.

============================================================
16. PRIORITY CONTRACT
============================================================

Recommended global ordering:
Death / unconscious / grabbed
-> Immediate physical danger
-> Severe Injury / mandatory recovery
-> Task09 active Travel / Emergency Refuge ownership
-> Task13 Acute environmental survival
-> PTSD / immediate Threat avoidance
-> Extreme Vengeance
-> Task13 Preparation/Sheltering or weather aggression modifiers
-> formal Harass / Retaliation
-> Task12 signal influence
-> Task10 Neutral SocialLife
-> ordinary Roost / Swarm / Idle.

Nuance:
- immediate defensive escape remains valid in any weather;
- strong environmental pressure may shorten prolonged retaliation;
- hard weather can suspend Vengeance but never erase it solely because weather changed;
- Task09-owned frame always beats Task13 local shelter goal.

============================================================
17. TASK10 INTEGRATION CONTRACT
============================================================

Task13 changes weighting/gates only.
Task10 still owns partner/group/reservation state.

Relevant outputs consumed by Task10:
- SocialMultiplier;
- PlayMultiplier;
- GroupCohesionMultiplier;
- RoostMultiplier;
- LocalActivityRadiusMultiplier;
- HardSurvival gate.

General qualitative matrix:
Calm:
- all 1.0 baseline.

Preparation shelter-type weather:
- Companion modest decrease;
- GroupDrift may remain briefly;
- SocialChase strong decrease;
- PassBy decrease;
- Roost increase.

Acute:
- neutral play 0 or near 0;
- Roost/Survival only.

Heat exception:
- early Heat can temporarily raise SocialChase/agitation before ThermalExhaustion/ShelterDrive suppress it.

Task10 GroupDrift may provide weak social cohesion while bats independently move toward local shelter, but Task10 must never receive ownership of shelter navigation.

============================================================
18. FORMAL ATTACK / HARASS INTEGRATION
============================================================

Task13 does not replace DesertBatflyAI attack modes or AttackSlots.

Outputs:
- HarassMultiplier;
- DamageAttackPermission;
- possible weather-specific attack-state weighting modifier.

Heat:
- raises aggression permission before hard thermal survival dominates.

Sandstorm:
- proactive roaming aggression decreases;
- defensive aggression may rise around blocked Hive/Burrow access or when a returning bat is attacked.

Hard requirement:
DamageAttackPermission means an individual may enter damaging existing attacks when all normal target/slot/opportunity gates pass.
It does NOT mean the whole colony targets the player simultaneously.

============================================================
19. TASK11 THREAT SIGNATURE INTEGRATION
============================================================

Task13 must never mutate, clear or broadcast Task11 memory.

Task13 answers:
"Do I currently have environmental energy/permission to attack?"

Task11 answers:
"Given my learned experience with this player, how should I approach/evade/attack?"

Example IntenseHeat:
- DamageAttackPermission = high;
- Player has high Piercing + CounterKill memory;
- bat may still attack but Task11 keeps lateral/fake-dive/short-window tactics.

Fog/DenseFog:
- long-range CurrentCue / witness recognition may be reduced by VisibilityConfidence;
- close actual projectile threat must remain detectable.

============================================================
20. TASK12 SIGNAL INTEGRATION
============================================================

Task12 remains exactly six signals:
AlarmFlutter, DistressCall, RallySignal, RoostCall, HarassSignal, SafeSignal.

Task13 MUST NOT add:
- ShelterCall;
- SandstormCall;
- WeatherCall;
- FogCall;
- HeatCall.

Each bat senses DryCycle weather independently.
Natural group coordination uses existing downstream signals:
weather causes A to Roost -> A emits RoostCall -> B/C may follow through Task12 + Task10.

AlarmFlutter:
- never used as normal weather forecast;
- only true acute local environmental incidents may emit anonymous hazard alarm.

SafeSignal:
- not weather recovery;
- Recovery is Task13-owned.

Fog:
- visual Task12 signal range scales with VisibilityConfidence;
- Alarm/Distress close acoustic/flutter channel remains available.

============================================================
21. LOCAL SHELTER FAILURE -> TASK09
============================================================

Task13 may report only bounded evidence, never migration intent.

Possible report conditions:
- serious DryCycle weather is actually active;
- Task09 considers current Home/room theoretically adequate;
- realized Task13 has no usable anchors OR all reasonable anchors remain severely overcrowded OR individual/room exposure stays high despite commitment;
- condition persists over a meaningful window, not one frame.

Initial persistence baseline:
- no report before ~300-600 continuous ticks of materially failed shelter during serious active weather;
- require repeated or sustained evidence before another report;
- cooldown at least several hundred ticks / preferably once-per-event bounded reporting.

Report fields conceptually:
- room;
- weather family;
- severity;
- no-anchor / overcrowding / persistent-exposure reason;
- bounded strength.

Task09 alone decides long-term consequence.

============================================================
22. WEATHER FAMILY COMPOSITION
============================================================

Do not blindly add every modifier.
Resolve a DominantProfile plus compatible secondary axes.

Rules:
- HeavyRain dominates LightRain shelter behavior.
- LightRain may provide weak moisture/cooling benefit but cannot cancel HeatWave/IntenseHeat.
- Fog can coexist with LightRain because visibility and moisture are orthogonal.
- DangerType hard survival dominates neutral weather.
- avoid double counting Weather + DangerType versions of one family.
- Sandstorm migration-execution suppression may coexist with long-term Task09 weather stress accumulation.

Suggested family priority for dominant hard behavior:
DeathRain / DeathSandstorm / IntenseHeat
> active severe Sandstorm / severe Heat
> DenseFog / HeavyRain
> Fog / LightRain.

This is ecological dominance, not rendering priority.

============================================================
23. LIGHTRAIN PROFILE
============================================================

Identity:
weak disturbance + minor moisture opportunity.
Not miniature HeavyRain.

Source:
DryCycle LIGHTRAIN only.
Default visual rain/effects do not count unless owned by DryCycle weather runtime.

Phase ceiling:
LightRain alone may reach only Calm/weak Advisory.

Baseline modifiers at full LightRain intensity, before individual weighting:
- ShelterDrive: +0.05 to +0.12;
- OpenExposureAversion: +0.02 to +0.08;
- RoostMultiplier: ~1.05-1.15;
- HarassMultiplier: ~0.90-0.98;
- SocialMultiplier: ~0.95-1.00;
- PlayMultiplier: ~0.90-0.98;
- ActivityRadius: ~0.92-1.00.

Healthy bold bats can be almost unchanged.
Injured / low-Nerve / high-RoostAffinity bats respond more visibly.

Moisture benefit:
- only if RainExposure at bat position is real and roof protection does not block it;
- slow simple dehydration relief only;
- no special drinking Activity/animation;
- do not route through the player's full thirst system.

Task09:
- no EmergencyRefuge solely due to LightRain;
- Task13 does not add permanent migration stress.

Signals:
- no Alarm solely because LightRain is active;
- no Safe when LightRain ends.

Recovery:
~80-200 ticks for individuals who actually contracted; many bats need no visible Recovery.

============================================================
24. FOG PROFILE
============================================================

Identity:
moderate visual-confidence loss -> reduced willingness for long-range activity.
Not a shelter emergency.

Source:
DryCycle FOG only.
RoomSettings Fog alone MUST do nothing.

Baseline at strong ordinary Fog:
- VisibilityConfidence ~0.65-0.80;
- ActivityRadius ~0.70-0.88;
- HarassMultiplier ~0.65-0.85 for long-range proactive harassment;
- SocialMultiplier ~0.80-0.95;
- GroupCohesion may modestly increase for nearby companions;
- RoostMultiplier ~1.00-1.15.

Behavior:
- less Solo roaming;
- fewer long SocialChases;
- less distant Harass;
- local Companion/PassBy/small Group remains.

Task09:
ordinary Fog alone does not request cross-room weather refuge.

Task10/11/12 visual ranges:
scale selected visual-only searches by VisibilityConfidence rather than changing every game LOS API globally.

Immediate close projectile danger remains valid.

============================================================
25. DENSEFOG PROFILE
============================================================

Identity:
severe loss of visual/navigation confidence; current room may become temporarily unsuitable for normal life.

Source:
DryCycle DENSEFOG only.

Baseline severe DenseFog:
- VisibilityConfidence ~0.25-0.45;
- ActivityRadius ~0.35-0.60;
- HarassMultiplier ~0.15-0.45;
- Play/Social long-range actions strongly reduced;
- RoostMultiplier ~1.35-1.90;
- HomeReturnDrive materially increased;
- NavigationUncertainty high.

Navigation model:
Do NOT force random crashes.
Instead reduce anticipation quality.

Suggested implementation:
- ObstacleAnticipationScale = lerp(1.0, ~0.35-0.55, DenseFog severity);
- long-range target error radius may rise roughly 10-55 px depending on severity/distance;
- target error decreases toward zero inside short range (~80-120 px);
- stable short-lived error seed (not new random every frame) prevents jitter;
- actual Fly collision produces the occasional wall bump naturally.

Home familiarity modifier:
- Home/Hive room may reduce error by ~25-45%;
- known local Roost/Shelter anchor reduces error further;
- unfamiliar transit room receives no such bonus.

Task09 displacement:
If local DenseFog is severe and room usability falls below threshold, Task13 may request/score a temporary weather-displacement need through Task09.
Task09 decides the actual room/route.

Allowed result:
DenseFog Home -> nearby clearer viable refuge -> temporary displacement -> fog clears -> ReturnHome.

Forbidden:
- Task13 choosing destination room;
- one DenseFog event directly creating permanent ColonyMigration.

Recovery:
VisibilityConfidence and activity radius restore over roughly 180-600 staggered ticks depending on prior severity, Injury and Nerve.

============================================================
26. HEAVYRAIN BASELINE PROFILE
============================================================

HeavyRain has not yet received the same dedicated specialty discussion as Heat/Fog/Sandstorm.
Implement only this approved baseline unless later Task13 revision explicitly expands it.

Identity:
classic roof/covered-space shelter weather.

Baseline effects:
- strong RainExposure avoidance;
- RoofShielding valued strongly;
- RoostMultiplier rises;
- open-sky activity falls;
- proactive Harass and SocialChase fall;
- multiple covered anchors distribute the colony.

Task09 decides cross-room Refuge when Home/current room is inadequate.

Do NOT invent HeavyRain-exclusive aggression/social signaling systems.

============================================================
27. HEATWAVE PROFILE
============================================================

Identity:
Heat causes agitation/aggression AND growing shelter/exhaustion simultaneously.

Required independent axes:
1) HeatAgitation
2) HeatShelterDrive
3) ThermalExhaustion

Never collapse them into one "heat activity scale".

Initial response-curve intent by normalized effective thermal burden T:
T~0.2:
- Agitation ~0.10-0.20;
- Shelter ~0.03-0.08;
- Exhaustion ~near 0.

T~0.4:
- Agitation ~0.30-0.45;
- Shelter ~0.10-0.20;
- Exhaustion beginning.

T~0.6:
- Agitation ~0.60-0.75;
- Shelter ~0.35-0.50;
- Exhaustion moderate.

T~0.8:
- Agitation ~0.75-0.90;
- Shelter ~0.65-0.80;
- Exhaustion high.

T~1.0:
- latent Agitation remains high;
- Shelter ~0.90+;
- Exhaustion very high, usually suppressing prolonged activity.

Effective burden should include:
- DryCycle Heat intensity/local ThermalExposure;
- exposure duration;
- Dehydration penalty;
- Injury/PhysicalCapability;
- derived HeatTolerance.

Early Heat behavior:
- Harass/FakeDive/Dive willingness increases;
- some SocialChase may increase;
- high Temperament converts agitation strongly.

Middle Heat:
- population visibly splits;
- some active/aggressive individuals remain;
- others seek shade/Roost/Home.

Long/severe Heat:
- shelter/exhaustion wins for more individuals;
- long-range flight/neutral play drops;
- shaded legal Roosts become valuable;
- exposed legal Roosts remain poor choices.

Aggression permission:
ordinary HeatWave may broaden damage-capable attack permission to bold healthy and some medium individuals.
It does not make low-Nerve/severely injured bats universally violent.

============================================================
28. INTENSEHEAT / DANGER HEAT PROFILE
============================================================

Identity:
extreme agitation + broad damage aggression permission + hard heat survival.

Required outputs:
- HeatAgitation very high;
- HeatShelterDrive very high;
- ThermalExhaustion grows quickly;
- DamageAttackPermission available to a majority of healthy adult bats before/while hard shelter has not fully committed.

Damage permission eligibility baseline:
Start with health/capability gate, then personality/exposure.
A healthy adult with adequate capability should commonly qualify.
Strong vetoes:
- severe Injury;
- unconscious/grabbed;
- Task09 travel ownership;
- current hard environmental commitment;
- severe PTSD where existing AI forbids aggression;
- very low PhysicalCapability.

Permission is NOT automatic aggro.
Formal AttackSlots and existing AI target/opportunity gates remain mandatory.

Population split target:
- substantial fraction Home/Hive;
- substantial fraction long Roost;
- substantial fraction Burrow where legal;
- smaller remaining outdoor active set biased toward healthy high-Nerve/high-Temperament individuals;
- outdoor group may be numerically smaller yet substantially more dangerous.

Long environmental Roost:
- can persist far beyond normal RoostDuration;
- should often cover much of the intense event peak;
- can be interrupted by direct danger, grab or Task09 ownership.

Burrow:
reuse existing Burrow/Emergence.
Task13 increases preference/commitment only.
Do not add HeatBurrow Activity.

Same-room Home/Hive retreat = Task13.
Cross-room return/refuge = Task09.

Vengeance:
may be fierce while still active, but hard thermal survival suspends without clearing state.

============================================================
29. SANDSTORM PROFILE
============================================================

Identity:
species-specific anticipatory Home retention.
Travel outside is itself dangerous.

Core outputs:
- HomeReturnDrive strongly up;
- BurrowDrive strongly up;
- RoostMultiplier strongly up;
- OpenExposureAversion strongly up;
- discretionary travel down;
- proactive Harass down;
- WeatherMigrationSuppression strongly up.

Unique anticipation:
Desert Batfly reacts substantially earlier to Sandstorm than ordinary weather.
Use only bounded DryCycle forecast data.
No full-cycle scheduler omniscience.

Current global forecast bridge is roughly a few minutes; Sandstorm may use a large portion of this permitted horizon.
Initial tuning baseline within an allowed ~7200 tick ecological horizon:
- Advisory may begin ~6000-7200 ticks before serious onset when Sandstorm forecast is valid;
- Preparation may begin ~3500-5000 ticks before onset depending on severity/personality;
- strong Home/Roost/Burrow contraction may begin ~1500-3000 ticks before onset;
- individual timing varies strongly by Nerve, Injury, RoostAffinity and stable seed.

These are tuning baselines, not scheduler truth.
Never inspect farther future than the ecological bridge exposes.

Visible early signs:
- far-roaming radius shrinks;
- SocialChase declines;
- ordinary Harass declines;
- early responders drift/return toward same-room Home/Hive;
- Roost/Burrow occupancy rises progressively.

Player-facing target:
experienced players can infer an approaching Sandstorm by Desert Batfly behavior before the storm is visually severe.

Shelter geometry:
priority is enclosure + side shielding + roof.
If actual wind vector becomes available, prefer lee-side/wind-shielded anchors.
Without wind vector, use enclosure/nearby walls as fallback.

Attack behavior:
- proactive roaming aggression decreases;
- defensive aggression may increase if Player blocks Hive/Burrow access or attacks a returning bat.

Task12:
no SandstormCall.
Existing RoostCall provides secondary social coordination.

============================================================
30. SANDSTORM MIGRATION/TRAVEL GATE
============================================================

Important distinction:
Sandstorm may still contribute long-term Task09 habitat stress, but it suppresses STARTING migration/travel at unsafe times.

During strong Sandstorm Preparation or active Sandstorm:
- do not start a new permanent ColonyMigration batch;
- discretionary cross-room movement heavily suppressed;
- prefer Home/Burrow/Roost/local shelter.

Emergency outward refuge is allowed only if ALL are true:
- current Home/location materially unsafe;
- candidate refuge materially safer;
- route is short enough and survivable;
- enough lead time remains before serious storm;
- Task09 approves the route.

Once serious Sandstorm is already active:
- do not start long cross-room relocation.

Already traveling individuals:
Task09 decides whether to continue, replan, abort toward nearest safe location or return Home.
Task13 does not issue world movement.

============================================================
31. DEATHSANDSTORM PROFILE
============================================================

Identity:
hard Home-retention survival with the strongest useful pre-onset anticipation.

Before onset:
- early retreat is critical;
- Home/Burrow/long Roost begins well before lethal conditions;
- new permanent migration prohibited once strong preparation starts.

After high danger begins:
- long-distance relocation normally prohibited;
- only extremely short, clearly survivable emergency retreat to materially safer refuge may be accepted by Task09;
- ordinary SocialLife/Harass/Vengeance movement suspended by hard survival.

Do not clear Vengeance state solely because of weather.

============================================================
32. DENSEFOG VS SANDSTORM TRAVEL STRATEGY
============================================================

This distinction is mandatory.

DenseFog:
- current room can become unusable because vision/navigation confidence is poor;
- route to nearby clearer room may remain viable;
- temporary weather displacement can be sensible.

Sandstorm:
- outside route is itself hazardous;
- default strategy is Home retention / Burrow / Roost / local shelter;
- outward displacement needs much stronger justification and preferably happens before serious onset.

Never implement generic:
BadWeather -> NearestRefuge.

33. DEATHRAIN BASELINE PROFILE
============================================================

DeathRain is hard survival.

Task09:
- pre-onset cross-room refuge/route decision;
- unsafe long travel should not begin after lethal late onset.

Task13:
- if current room is accepted as survivable location, Acute local shelter behavior dominates.

Do not invent extra DeathRain-exclusive social/aggression mechanics without later discussion.

============================================================
34. RECOVERY MODEL
============================================================

Recovery is not weather intensity simply returning to zero.
It is a staggered behavioral release layer.

Per-individual recovery delay should use:
- prior event severity;
- Nerve (high recovers earlier);
- Temperament (may resume earlier);
- Injury/PostStunShock (later);
- Trauma where appropriate only as existing state, not new weather trauma;
- stable EntityID offset.

LightRain:
~80-200 ticks, often invisible.

Fog:
~120-300 ticks.

DenseFog:
~180-600 ticks, including gradual visibility confidence restoration.

HeatWave:
~180-500 ticks; ThermalExhaustion may decay slower than HeatAgitation.

IntenseHeat:
~300-900+ ticks depending on exhaustion/severity; long Roost/Burrow individuals need not emerge together.

Sandstorm:
~240-700 ticks; Home/Burrow/Roost occupants resume gradually.

DeathSandstorm/DeathRain:
longer safety hold is acceptable before ordinary play/Harass resumes.

Recovery ordering target:
1) healthy high-Nerve/high-Temperament individuals;
2) ordinary healthy individuals;
3) low-Nerve / exhausted;
4) injured/high-shock individuals.

No synchronized mass release.

45. FINAL ECOLOGICAL IDENTITY
============================================================

LightRain:
near-normal desert ecology with small moisture/rest differences.

Fog:
less confidence and shorter range, while local life continues.

DenseFog:
normal life becomes difficult; Home/Roost/nearby clearer temporary refuge become plausible and navigation visibly loses precision.

HeavyRain:
classic covered-space shelter behavior.

HeatWave:
first more agitated/aggressive for suitable individuals, then progressively more shelter-driven/exhausted.

IntenseHeat:
many healthy bats gain real damage-attack permission while much of the colony simultaneously disappears into Home, long Roost or Burrow; fewer visible bats can be more dangerous.

Sandstorm:
early sensed Home-retention event; bats prepare before onset and strongly prefer not to travel outward.

DeathSandstorm:
strong pre-onset retreat and hard late survival; long late relocation is nearly absent.

DeathRain:
hard survival; Task09 decides cross-room safety before onset and Task13 handles local Acute shelter if staying.

The final colony must look like many individuals with different thresholds responding to one environment, not one synchronized weather script.
