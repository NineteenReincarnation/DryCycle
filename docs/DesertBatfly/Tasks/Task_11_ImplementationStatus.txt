Implemented architecture
------------------------
1. Three distinct layers exist:
   - persistent per-player Threat Signature Memory;
   - realized-only Current Threat Cue;
   - realized-only Acute Event state.
2. Persistent memory contains exactly the agreed twelve continuous dimensions plus Confidence/decay bookkeeping.
3. Four fixed player slots are stored independently for co-op.
4. Evidence uses saturating updates and per-cycle decay.
5. Save data uses the independent versioned key DCDesertBatflyThreatV1 and safely defaults when absent.
6. ThreatEvent/ThreatTag + adapter registry separates item identity from event semantics.
7. Spear, Rock, Firecracker/Startle, explosive threats, Shock, Grab, Pursuit, CounterKill, Retreat and NonAggression are represented without a permanent style enum.
8. Held-item recognition is Current Cue only; it does not train long-term memory.
9. Shock/Startle/Explosion long-term evidence requires the corresponding real event semantics rather than item-name recognition alone.
10. Direct victim evidence is stronger than LOS witness evidence; witness learning is room-local, distance/LOS-gated and event-driven.
11. SocialBond is only a weak witness significance bonus; detailed player threat signatures are never copied through the colony.

Tactical integration
--------------------
- Learned Projectile/Piercing/CounterKill biases FakeDive/Probe probability without forcing one deterministic tactic.
- Observe/Circle/Approach/Dive/Attach/Retaliation geometry reads the current target player's own memory slot.
- Visible Spear/Rock/Explosive/Startle/Shock cues only strengthen already-learned caution for the current frame.
- Real incoming projectile trajectories can produce a short lateral evade localGoal.
- Ordinary projectile evade reuses the same validated trajectory geometry used by the Extreme Vengeance bridge.
- Projectile dodge changes FlyAI.localGoal only; native Fly locomotion retains velocity/collision ownership.
- Rock/Blunt learning does not create a persistent high-Y flight controller.
- Explosion/AreaDenial uses real acute hazard centers; long-term memory never invents invisible hazard space.
- GrabCapture raises close-range/Attach suppression.
- Pursuit and CounterKill use different event windows and different behavioral feedback.
- RetreatTendency and NonAggressionConfidence build slowly and only provide limited relief.

Priority boundaries
-------------------
- death / unconscious / restraint / shortcut remain survival ownership boundaries;
- real incoming projectile remains an immediate-danger cue;
- Severe Injury recovery is evaluated before learned attack weighting;
- strong player-specific Trauma/PTSD still vetoes ordinary harass, attack-slot acquisition and retaliation;
- Task09 successful realized travel owns its exact frame and later Intimidation/Vengeance cannot steal that frame back;
- Extreme Vengeance is never cancelled by Threat Signature Memory; Task11 only changes attack geometry and short projectile evasion;
- Task10 neutral SocialLife yields to incoming projectile, Acute Event, combat and Task09 control.

Performance structure
---------------------
- room-scoped Current Cue cache refreshes at low frequency instead of every bat scanning all objects every frame;
- witness learning runs only when meaningful events occur, not as a per-frame N x N pass;
- persistent memory is fixed-size per bat (four player slots), not an unbounded dictionary;
- ordinary projectile evade resolves the player through RainWorldGame.Players rather than scanning every room creature;
- Debug/Trace strings are constructed only for watched/debug paths;
- Task11 adds no second tile pathfinder and no long-term direct velocity locomotion controller.
