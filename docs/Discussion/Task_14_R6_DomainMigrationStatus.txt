======================================================================
1. R6 closure decision
======================================================================

R6 closure is based on the actual production tree and guards, not on file size or on the historical Task-number layout.

Current closure invariants:
- no production Desert Batfly C# remains at the creature root;
- production Desert Batfly filenames use DB_ domain identities;
- historical DesertBatflyXxx internal type declarations are retired;
- production Task-number development terminology is absent under the permanent regex policy;
- Behavior/ThreatSignature physical ownership is retired;
- Fear and Vengeance are separate formal responsibility owners;
- Social, Threat, Signal, Environment, Travel and Colony have formal domain owners;
- EventHub, RoomContext, FrameContext, BehaviorArbiter and FlightMotor remain the architecture foundation;
- published/save/world compatibility identities remain unchanged;
- managed tests target the current domain architecture rather than retired façade identities.

The production tree is domain based:

Core:
- DB_Creature
- DB_Definition
- DB_State
- DB_Personality
- DB_Tuning
- DB_Runtime
- DB_EventHub / DB_EventConsumers

- DB_FlightMotor

Behavior:
- DB_AI

- Combat / Injury / Perception / Roost / Signals / Social / Threat owners

World:

Integration / Presentation / Debug remain explicit boundary domains.
