2. 已完成架构
======================================================================

2.1 DB_RoomContext
--------------------

文件：

src/Creatures/DesertBatfly/Runtime/DB_RoomContext.cs

统一缓存：

- Creatures；
- Bats；
- Players；
- Weapons；
- ThrownWeapons。

设计：

- ConditionalWeakTable<Room, DB_RoomContext>；
- 按 consumer 请求 lazy 创建；
- RefreshIntervalTicks = 8；
- 同一 refresh window 内多个 bat / domain 共用同一快照；
- 只缓存 observation，不拥有 Social / Threat / Environment / Travel 的领域状态；
- 暴露 RefreshCount / CreatureScanCount / PhysicalObjectScanCount 供后续性能与 Observatory 验收；
- species Enable / Disable 时 Reset。

2.2 DB_VisibilityPolicy
--------------------

文件：

src/Creatures/DesertBatfly/Perception/DB_VisibilityPolicy.cs

统一 channel：

- Creature；
- Player；
- Social；
- Signal；
- HeldItem；
- Projectile。

规则：

- Room.VisualContact 仍是 terrain LOS authority；
- 只有已经验证的 DryCycle Environment VisibilityConfidence 能调整感知距离；
- RoomSettings Fog / shader fog / palette 本身不能激活 DesertBatfly ecology；
- clear weather visibility=1 保持原基础范围；
- Fog / DenseFog 降低远距 recognition；
- real projectile 保留 bounded close fallback；
- close projectile floor 当前为 90 px，仍必须通过真实 LOS。

2.3 DB_WeaponPerception
--------------------

文件：

src/Creatures/DesertBatfly/Perception/DB_WeaponPerception.cs

统一能力：

- TryFindIncomingProjectile；
- TryFindIncomingProjectileFrom；
- TryFindImmediateThreat；
- TryObserveHeldThreats。

保留旧行为：

- thrown weapon trajectory / closest approach；
- close moving-held Spear immediate reaction；
- instigator recognition；
- held Spear / Rock / explosive / startle / shock current cue。

该层不：

- 训练 persistent Threat Memory；
- 写 localGoal；
- 写 BodyChunk.vel；
- 决定 behavior owner。

4. 已删除旧 visual bridge
======================================================================

以下生产文件已经删除：

- Environmental/DesertBatflyEnvironmentalSignalBridge.cs；
- Environmental/DesertBatflyEnvironmentalThreatBridge.cs。

原因：

它们原本依靠 Reflection + RuntimeDetour 把 Fog/DenseFog 影响注入 Task12/Task11 私有方法；R2 已把同一职责变成正式的 DB_VisibilityPolicy / DB_WeaponPerception API。

继续保留会造成：

- 双重缩距；
- 第二套 signal range authority；
- 第二次 close projectile scan；
- 私有方法改名时的 runtime silent failure。

Task13 regression 已从“bridge 必须存在”的 Architecture Lock 改成：

- 旧 visual bridge 必须不存在；
- shared visibility / weapon perception behavior contract 必须存在。

这属于 Task14 计划中的正式技术债删除，不改变 Task13 weather ownership。

5. irrelevant-room lazy activation / HB-08
======================================================================

DesertBatflyHooks.UpdateRoom 当前顺序：

1. vanilla Room.Update；
2. DesertSwarmRoom.UpdateRoom；
3. 查询 DB_RoomContext.TryGetExisting；
4. 若没有 active DesertBatfly context 或 Bats.Count == 0，则停止 DB-only room work；
5. 只有 active DB room 才执行：
   - Refuge.ObserveRoom；
   - SignalRoomRuntime.Prune；
   - EnvironmentalRoomRuntime.Update。

重要：

DesertSwarmRoom 没有被 lazy gate，因为 DESERTSWARMROOM spawning/hive semantics 必须在蝠蝇 realized 之前仍可工作。

因此 HB-08 的代码侧问题关闭：

普通无 DesertBatfly relevance 的 realized Room 不再因为全局 Room.Update hook 主动建立 shelter anchors / Signal RoomState / Refuge observation。

6. R2 性能意义
======================================================================

- 每 bat AI creature scan；
- 每 bat AI physicalObjects weapon scan；
- ThreatRuntime 第二套 Player/ThrownWeapon room scanner；

R2 后：

Room observations：

DB_RoomContext
    -> Creatures / Bats / Players / Weapons / ThrownWeapons

Perception：

DB_VisibilityPolicy
DB_WeaponPerception

Domain decisions：

AI / Threat / Signal / Social
    -> consume observation
    -> 保留自己的领域规则

没有把多个 bat 的 Personality/decision 合并成群体控制器。
