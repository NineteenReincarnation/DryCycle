1. Scope
======================================================================

R7 is the final performance/debug/full-regression phase after R6 architecture closure.

R7 does not reopen domain ownership merely to make files smaller or code visually different. Changes should be driven by measured or strongly demonstrated runtime cost, debug blind spots, live-regression failures, save compatibility issues, or genuine architecture regressions.

This status records only work actually completed or verified. It does not claim the required live Rain World acceptance work has occurred.

======================================================================
2. R7-A1 static hot-path audit
======================================================================

A one-shot candidate audit inspected the main Desert Batfly hot paths for:
- room physical-object scans;
- abstract creature scans;
- Hive.flies scans;
- string interpolation in update paths;
- ToArray allocations;
- explicit List/Dictionary/HashSet allocations;
- LINQ-style enumeration;
- duplicate room-observation ownership.

The audit distinguished persistent 20–30-bat costs from low-frequency/debug/event allocations. It deliberately did not refactor every allocation it found.

Low-frequency/debug allocations intentionally left alone include:
- small Social reservation lists created on interaction setup;
- BehaviorArbiter debug-state ToArray materialization when a debug snapshot is requested;
- event/watch/debug trace strings;
- Travel collection initialization/reset work;
- Colony abstract-population ecology scans that legitimately belong to the World/Colony domain.
