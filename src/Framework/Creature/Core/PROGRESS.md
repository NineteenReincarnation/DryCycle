# Creature Core 开发进度

这个文件只记录 `src/Framework/Creature/Core` 里已经真正完成的工作。

记录时尽量说人话，不只写类名、接口名或内部实现细节。每完成一个 Core 任务，都要同步更新这里。

## 已完成

- 建好了生物 Core 框架目录，后续通用的生物核心轮子统一放在这里。
- 做好了生物注册说明书：可以登记一种生物是谁、属于哪个 Mod、显示名称叫什么，以及它在 `world.txt` 等地方还能用哪些别名识别。
- 做好了生物核心对象的创建登记：开发者可以分别告诉框架该怎么创建生物模板、状态、实际生物、抽象 AI 和实际 AI；不需要自定义的部分可以留空，继续走 Rain World 原版流程。
- 做好了注册信息冻结保护：一份生物说明书一旦正式交给注册系统，就不能再被偷偷修改，避免运行时登记信息前后不一致。
- 做好了生物别名管理：别名忽略大小写去重，保留第一次填写时的顺序，并且外部代码不能绕过接口直接修改。
- 做好了更简洁的注册写法：在保留完整 API 的同时，增加了 `Name`、`Alias`、`Aliases`、`Template`、`State`、`Realized`、`AbstractAI`、`AI` 这些短写法，功能不变，但注册代码更短、更容易读。
