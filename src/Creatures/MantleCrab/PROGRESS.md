# MantleCrab 当前进度

## 状态说明

【未测试】代码已经完成或已经进入主分支，但还没有经过完整的游戏内实际测试。

【已检查】已经做过代码结构检查、静态检查或已有明确画面检查，但仍可能需要后续实机回归。

【测试失败】已经进行过实际游戏测试，并确认当前实现存在需要重构或修复的问题。

【未开始】目前还没有正式开始制作。

## 已完成内容

【已检查】已经完成 MantleCrab 的基础生物注册、状态创建和实体创建流程，能够作为独立生物进入项目现有的生物注册体系。

【已检查】已经完成五个身体碰撞块组成的刚性甲壳结构，并加入完整的身体连接关系、质量分配、重心处理和刚体形状维持。甲壳在受到碰撞后会保留整体平移和旋转反应，同时消除内部拉伸、弯折和压缩。

【已检查】已经完成甲壳顶部的动态可站立表面。玩家和其他符合条件的实体可以把甲壳顶部当作移动平台使用，甲壳运动后会继续维护表面几何关系。

【未测试】已经完成四条承重步足的骨架、关节求解、落脚点、支撑状态和地面法线处理。V2 已把无约束折线式 IK 改成带关节角限制的求解，并给正常站姿保留真实的关节活动余量。

【未测试】已经完成四足稳定性驱动步态。螃蟹不会固定按照机械顺序迈腿，而是根据腿的伸展程度、理想落脚位置、当前支撑稳定性和上一次迈腿情况选择下一条腿。

【未测试】已经完成步足的抬脚、摆动和重新落地过程。落脚位置会根据当前移动方向和身体速度进行提前预测，再寻找真实可承重地面。

【未测试】已经完成基础地面移动 V2。移动方向已经与甲壳当前旋转角彻底解耦，推进只沿由世界重力和地面支撑建立的地面行走轴进行；甲壳被撞歪以后不会再把斜向或向上的甲壳 Axis 当成推进方向。

【未测试】已经完成地面姿态与失衡恢复 V2。甲壳只允许在地面参考框架附近小幅倾斜；超过恢复阈值后停止正常推进和主动换步，关闭人工倾斜并优先回正。恢复采用迟滞阈值，避免在临界角度反复切换状态。

【未测试】已经补充翻倒后的无足支撑自救。即使四条步足全部丢失有效 Plant，只要甲壳 BodyChunk 实际接触地形，甲壳仍会利用壳-地接触产生回正滚动力矩；空中不会凭空自转。接近 180 度倒扣时会锁定一个翻身方向，避免在正负 PI 附近反复换向。

【未测试】已经完成承重分配 V2。两侧都有可靠脚点时，支撑力会按重心位置在左右支撑之间分配，避免单侧腿因为权重偏差把甲壳越撑越翻；只有单侧支撑时不允许完整托住整只螃蟹，只保留有限支撑让身体继续寻找另一侧落脚点。

【未测试】已经完成足端接触卸载与局部滑移 V2。脚接近关节工作空间边缘时会先沿地面做有限滑移释放应变，超过安全伸展后直接卸载，不再允许旧落脚点一直粘到接近 100% Reach。

【未测试】已经完成生成站高修正 V2。生成点靠近地面时会先把甲壳放到接近自然站高，再让步足建立支撑，避免刚生成时用数百像素的高度误差把整个身体弹飞。

【未测试】已经完成缓慢身体倾斜控制。Safari 的上下输入现在只产生有限的姿态倾斜意图，不再把甲壳旋转结果当成新的移动方向。

【未测试】已经完成复杂地形的局部探测和通过规划。当前会区分普通地面、粗糙地面、上台阶、下台阶、跨窄沟和不可通过地形；V2 中这些判断统一使用稳定的地面行走轴，不再跟随失控旋转的甲壳 Axis。

【未测试】已经完成上台阶的前导腿探测逻辑。前方腿会先寻找更高的稳定支撑点，建立新支撑后再逐步转移身体重量，不会直接给甲壳增加向上的假位移。

【未测试】已经完成下台阶的探脚逻辑。前方支撑突然降低时会减速、降低身体并向低处寻找新落脚点，避免直接从边缘整只掉下去。

【未测试】已经完成窄沟桥接逻辑。如果沟的另一侧仍处于真实腿部工作范围内，前导腿可以先跨到另一侧建立支撑，再让身体和后腿跟进。过宽沟和悬崖会停止前进。

【未测试】已经完成困难地形下的动态身体高度调整。粗糙地面、台阶和沟壑会让螃蟹通过关节折叠降低身体，从而增加腿部可用工作空间，而不是临时增加腿长。

【未测试】已经加入临时移动测试 AI。它不包含正式寻路、感知或战斗，只会持续巡航、定时换向，在 Traversal 判定不可通过或长时间没有实际位移时停顿并反向，用于自动暴露步态和复杂地形问题；Safari 控制时不会覆盖玩家输入。V2 的卡住判定也已改为沿地面行走轴计算。

【已检查】已经完成两只钳子的独立解剖骨架和关节结构。钳子具有自己的多节结构、关节滞后、开合状态、手腕和掌部朝向，不与承重步足共用同一套姿态逻辑。

【未测试】已经补充钳子的步态二级运动。近端仍牢固跟随甲壳，越靠近远端越有惯性滞后；左右钳采用相反步态相位，身体加减速时远端产生有限反向拖曳；甲壳倾斜或翻倒时，远端会逐渐偏向世界重力方向悬垂，不再整条刚性跟壳旋转。

【未测试】已经补充移动自然化处理。高层 MoveIntent 会先平滑再进入步态，推进加速度具有变化率限制，换向不再瞬时满制动/满加速；稳定性驱动步态保留，同时加入很弱的对角节律偏好，并给甲壳加入约 1 像素级的负载节律起伏，减少机械式匀速滑动感。

【已检查】已经完成 MantleCrab 的基础绘制体系，包括甲壳、眼睛、步足、钳子和个体外观差异。步足外观目前仍在继续调整，尤其是末端足部、各节比例、关节错位和前后腿默认姿态。

## 移动系统测试记录

【测试失败】基础移动 V1 已在 2026-09-11 的实机录像中确认存在结构性问题：生成高度错误导致巨大的初始支撑误差；无约束 IK 允许腿反折和翻面；落脚点粘到接近极限 Reach；支撑力与肢体机械状态脱节；甲壳实际旋转角同时污染推进方向、步足 Rest Pose、稳定性判断和 Traversal 扫描，最终形成甲壳倾斜后向上推进、腿像橡皮筋一样拉扯并持续弹飞的正反馈失控。

【测试失败】同一轮移动录像还明确暴露了三个后续问题：甲壳完全翻倒后在四脚失去有效支撑时无法继续执行回正；红色长钳在步行和身体运动中缺少对应的节肢二级动作；地面移动的输入、推进和换步节奏过于瞬时且均匀，整体表现机械死板。

【未测试】针对上述三个问题已经完成后续修正并进入 main：增加壳-地接触自救路径；增加钳子分段惯性、步态反相摆动和重力悬垂；增加 MoveIntent 缓动、推进加加速度限制、弱对角节律和轻微负载起伏。下一轮实机重点观察翻倒能否重新站起、钳子是否随身体产生连续关节波、以及平地巡航是否仍有明显机械匀速和瞬时换向感。

## 后续开发顺序

【未开始】第一项：钳子真实交互与战斗。让现在已经存在的钳子骨架真正具有抬钳、张开、瞄准、夹击、命中、夹住、保持和释放等能力。

【未开始】第二项：甲壳、防御、受伤和失衡。区分甲壳、腿部、腹部等受击位置，让不同部位拥有不同的防护、硬直和损伤结果。

【未开始】第三项：感知和行为状态。建立平静、警戒、威胁、战斗、逃避、觅食或游荡等内部状态，但不让高层行为直接控制每一条腿。

【未开始】第四项：寻路和移动能力映射。把已经存在的普通行走、上下台阶、跨沟和不可通过状态接入真正的房间寻路。

【未开始】第五项：生物关系和生态行为。确定它对玩家、拾荒者、蜥蜴、其他大型生物和食物目标的态度与反应。

【未开始】第六项：抓取、搬运和进食。根据最终生态定位决定钳子抓住目标后是否搬运、撕扯、进食或丢弃。

【未开始】第七项：跨房间、捷径和巢穴规则。处理进入捷径、离开房间、抽象化和重新实体化等完整世界行为。

【未开始】第八项：声音、粒子和战斗反馈。最后补充钳子碰撞声、甲壳受击声、脚步、灰尘和其他细节表现。
