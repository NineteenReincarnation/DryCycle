Desert Batfly 复杂机制讨论状态
================================

用途
----
本文件记录当前对 Desert Batfly 后续复杂 AI / 生态机制的讨论结论，用于后续整理 Codex 任务书。

状态定义：
- 【采纳】= 用户已经同意该方向，可以进入后续设计与任务书。
- 【采纳·待深入讨论】= 方向已经同意，但具体规则、参数、边界和实现方式还没有敲定，禁止直接按当前草案写最终实现。
- 【暂时否决】= 当前阶段暂不加入，不代表永久删除。后续讨论可以重新启用。

当前基线说明：
Desert Batfly 已经具有个体 Personality、Roost/Chain、普通骚扰与 AttackSlots、抓取记忆、喷沙、玩家/Peach 死亡威慑、有限链式恐惧、Conformity、Extreme Vengeance、Follower、PTSD/Trauma、Peach 捕食和尸体捡食等系统。以下内容是在这些已有机制上的下一阶段扩展。


1. Colony Social Reputation / 群落社会声誉
状态：【暂时否决】

原讨论方向：
- 玩家对一个 DESERTSWARMROOM 群落的长期行为形成弱社会声誉。
- 幸存目击者必须真实回到 Hive，才可能把“这个玩家危险 / 相对安全”的弱信息带回群落。
- 不能做成全房间或全区域心灵感应。
- 不同群落可以因为历史不同而表现出不同的整体警戒。

当前结论：
- 暂不进入任务书。
- 保留为未来可重新讨论的候选机制。


2. Emergent Social Roles / 涌现式社会角色
状态：【采纳】

核心方向：
- 不给每只蝠蝇硬编码固定职业 enum，而是让现有人格轴自然产生不同社会倾向。
- 可能表现为：Sentinel（哨戒）、Bully（骚扰者）、Follower（从众者）、Loner（独居者）、Watchful Scavenger 等。
- 角色是行为倾向，不应覆盖个体自己的 Temperament / Nerve / Conformity / Trauma / Thirst / Cooldown 等逻辑。
- 同一只个体在不同环境和状态下可以表现出不同“角色”。

当前结论：
- 可以进入后续设计。
- 后续需要在任务书里明确：角色必须是评分/倾向式，而不是永久职业标签。


3. Social Signal System / 群体信号系统
状态：【采纳】

核心方向：
- 沙漠蝠蝇之间可以通过真实可观察动作传播行为意图，而不是只靠隐藏数值。
- 候选信号包括：
  1) Alarm Flutter：危险警报；
  2) Rally Signal：极端复仇 / 集结前信号；
  3) Roost Call：倒挂 / 聚集倾向；
  4) Safe Signal：危险结束、恢复正常活动的社会反馈；
  5) Harass Signal：普通骚扰意图。
- Conformity 决定个体有多容易被这些信号影响，但不能强制复制动作。
- 信号应有视距/距离/时效限制，禁止全房间同步。

当前结论：
- 可以进入后续设计与任务书。


4. Injury & Experience / 伤病与经历后遗症
状态：【采纳】

核心方向：
- 非致死伤害不只是 Stun，还可以留下临时或中期行为后遗症。
- 候选包括：
  - 翅部受伤：最大速度、转向、飞行稳定性下降，更容易低飞/休息/被 Peach 捕获；
  - 重 Stun 后：临时降低胆量与攻击欲；
  - Peach Tongue Survivor：曾被 Peach 舌头抓住但被救下/逃脱后，获得更强 PredatorTrauma 或专门的 TongueAvoidanceMemory；
  - 严重创伤可以影响后续社交和复仇判断。
- 伤病不能让普通轻微受击永久废掉个体，必须有恢复过程。

当前结论：
- 可以进入后续设计与任务书。


5. Lightweight Social Bond + Sex / 轻量社会纽带 + 雄性/雌性
状态：【采纳·待深入讨论】

已经采纳的 SocialBond 方向：
- 每只蝠蝇只维护极少量重要社会关系，优先考虑最多 1 个 FavoredCompanion，避免完整关系图带来复杂度与性能成本。
- SocialBond 可以来源于：
  - 成功救援；
  - 长时间稳定同一 Chain / Roost；
  - 多次一起逃生；
  - 未来可能加入的性别 / 配偶 / 繁殖相关关系。
- SocialBond 可能影响：
  - 更偏向一起 Roost；
  - 同伴遇险时更容易响应；
  - 同伴死亡造成更强 Trauma；
  - 更容易跟随该个体的社会动作或复仇；
  - 但仍不能强制覆盖自身 Fear / PTSD / Nerve。

用户新增并已采纳的方向：
- Desert Batfly 加入“雄性 / 雌性”的个体设定。

仍需深入讨论并敲定：
- 性别比例；
- 性别是否影响外观；
- 性别是否影响体型、行为、声音、攻击性或 Roost；
- 是否加入求偶；
- 是否加入配偶关系；
- 是否存在长期配对 / 临时配对；
- 是否真正进入繁殖、产卵、幼体或只做社会行为层；
- SocialBond 与配偶 / 亲属关系的优先级；
- 一方死亡后是否产生特殊 Trauma / 行为变化；
- 是否允许同性强 SocialBond；
- 性别设定应避免把 Temperament、Nerve 等人格轴简单绑定成性别刻板行为。

当前结论：
- 方向已经采纳。
- 在完成深入讨论前，禁止直接写最终任务书实现细节。


6. Resource Pressure / 资源竞争与群落内部冲突
状态：【暂时否决】

原讨论方向：
- 水源减少、群落密度、炎热天气形成 ResourcePressure。
- 高压力下增加玩家吸水骚扰、同类争抢、驱赶和 Roost 分散。

当前结论：
- 暂不加入。
- 不是永久删除，未来可以重新讨论。


7. Environmental Group Behavior / 环境与天气群体行为
状态：【采纳】

用户已明确采纳的核心：
- 恶劣天气或危险天气到来前，沙漠蝠蝇会提前回巢和躲避。

设计方向：
- 天气恶化不是瞬间全体消失，而应分阶段改变行为：降低飞行高度、减少骚扰、提高 Roost/Hive 倾向、逐步撤离。
- Conformity 可以影响撤离速度：高 Conformity 更容易跟随先行撤离的同伴。
- 高 Nerve / 低 Conformity 个体可以晚一些撤离，但最终仍应尊重真正危险天气。
- HeatWave 等沙漠天气可进一步影响活动高度、飞行消耗和躲避阴影/庇护区域的倾向。

当前结论：
- 可以进入任务书。
- “提前回巢和躲避”是硬要求。


8. Threat Style Memory / 玩家战斗风格学习
状态：【采纳·待深入讨论】

已采纳方向：
- Desert Batfly 可以根据某个具体玩家最近的战斗方式形成有限、可解释的 ThreatStyleMemory。
- 不是机器学习，而是少量稳定统计/记忆。

候选记忆：
- Spear-heavy：玩家频繁用矛击杀/投掷；
- Rock-heavy：玩家频繁用石头击晕；
- Passive/Fleeing：玩家长期只躲避；
- Counter-killer：玩家经常反杀攻击者；
- 未来可考虑其他明显武器/行为类型。

候选行为反馈：
- Spear-heavy：加大 Circle 半径、减少长直线 Dive、看到举矛/投矛准备时更早横向规避；
- Rock-heavy：增加短时规避和高度变化，但死亡威慑弱于 Spear；
- 玩家长期逃跑：恶劣个体的骚扰信心提高；
- 玩家连续反杀：降低靠近意愿，和现有 Trauma / Intimidation 协同。

必须深入讨论：
- 记忆是个体级还是群体可传播；
- 统计时间窗；
- 每类记忆如何衰减；
- 玩家具体动作识别到什么粒度；
- 是否读取玩家手持武器作为即时提示；
- 如何避免“读输入/作弊式预判”；
- 与 PTSD、GrabMemory、Conformity、Extreme Vengeance 的优先级；
- co-op 中必须绑定具体 Player；
- 不应让蝠蝇获得不合理的全知信息。

当前结论：
- 方向已经采纳。
- 必须深度讨论后再写最终任务书。


9. Colony Migration Pressure / 群落迁移
状态：【采纳】

核心方向：
- 如果某个 DESERTSWARMROOM 长期处于高死亡率、Peach 长期驻留、环境持续恶劣等状态，部分沙漠蝠蝇可以迁往相邻适合的群落房间。
- 目标是让群落数量和区域生态出现动态变化，而不是永远固定从同一 Hive 补满。
- 该机制会涉及 AbstractCreature / world population，必须和 realized AI 分层，不能每帧做跨房间扫描。
- 应存在迁移门槛、冷却和容量限制，避免人口在相邻房间之间来回抖动。

当前结论：
- 方向采纳，可以进入后续任务书设计。


10. Corpse Ecology / 尸体生态
状态：【采纳·待深入讨论】

已采纳方向：
- Desert Batfly 尸体不只是 Peach 的食物，也可以成为生态信息源和其他生物的资源。
- 已有基础：Peach 可以捡完整尸体或玩家吃剩但仍有 bites 的残骸并带回巢穴。

候选扩展：
- 尸体对活 Desert Batfly 形成弱 danger cue；
- 高 Conformity 个体更容易避开近期死亡点；
- 多具尸体可形成短期高危险区域；
- 某些 Scavenger / Predator 可能被尸体吸引；
- 尸体来源（玩家 / Peach / 其他捕食者）可能影响活体的风险判断；
- 尸体不应形成永久恐惧场，也不应每帧做全房间昂贵扫描。

必须深入讨论：
- 哪些生物会被尸体吸引；
- 是否做腐败 / 新鲜度；
- 尸体危险提示持续多久；
- 多尸体如何叠加；
- 是否影响迁移机制；
- 是否会造成捕食者聚集和二次生态反馈；
- 如何与现有 CorpseWarning、PlayerIntimidation、PredatorTrauma 去重，避免重复恐惧。

当前结论：
- 方向已经采纳。
- 必须深度讨论后再写最终任务书。
