Desert Batfly 复杂机制讨论状态
================================

用途
----
本文件记录当前对 Desert Batfly 后续复杂 AI / 生态机制的讨论结论，用于后续整理 Codex 任务书。

状态定义：
- 【采纳】= 用户已经同意该方向，可以进入后续设计与任务书。
- 【采纳·待深入讨论】= 方向已经同意，但具体规则、参数、边界和实现方式还没有敲定，禁止直接按当前草案写最终实现。
- 【采纳·部分已敲定】= 该大方向中已有一部分可以进入任务书，但仍有明确子项尚未进行额外深入讨论；Codex 只能实现已敲定部分。
- 【尚未进行额外深入讨论】= 已经列入正式讨论清单，但当前没有足够细节可直接实现，禁止 Codex 自行补完设计。
- 【暂时否决】= 当前阶段暂不加入，不代表永久删除。后续讨论可以重新启用。

当前基线说明：
Desert Batfly 已经具有个体 Personality、Roost/Chain、普通骚扰与 AttackSlots、抓取记忆、喷沙、玩家/Peach 死亡威慑、有限链式恐惧、Conformity、Extreme Vengeance、Follower、PTSD/Trauma、Peach 捕食和尸体捡食等系统。以下内容是在这些已有机制上的下一阶段扩展。


1. Colony Social Reputation / 群落社会声誉
状态：【暂时否决】

原讨论方向：
- 玩家对一个 DESERTSWARMROOM 群落的长期行为形成弱社会声誉。
- 幸存目击者必须真实回到 Hive，才可能把“这个玩家危险 / 相对安全”的弱信息带回群落。
- 不能做成全房间或全区域心灵感应。
- 不同群落可以因为历史不同而表现出不同的整体警戒。

当前结论：
- 暂不进入任务书。
- 保留为未来可重新讨论的候选机制。


2. Emergent Social Roles / 稀疏涌现式社会角色
状态：【采纳】

最终核心原则：
- 职业只是群落行为的点缀，不是整个物种的社会结构主体。
- 绝大多数 Desert Batfly 必须保持普通 / None，不需要显性职业。
- 正常群落目标观感：约 70%~85% 为普通个体，显性角色合计通常约 15%~30%。
- 正常约 11+3 的群落通常只出现约 2~4 个明显角色；允许某个群落只有 0~1 个，也允许偶尔略多。
- 不保证每个群落拥有所有职业，不允许按人数硬分配岗位。
- 普通 / None 仍然拥有完整 Personality、SocialBond、Trauma、Grief、Roost、Harass、Vengeance 等复杂逻辑。

正式显性角色只保留三种：
1) Sentinel / 哨戒者
   - 更常位于群落外围；
   - 更愿意观察潜在威胁；
   - 允许在安全距离主动靠近一点进行威胁确认；
   - 不应一看到玩家就立即全群报警；
   - 可以根据真实可观察行为逐步提高 ThreatConfidence；
   - 确认后复用现有 Alarm / Threatened / Fear 逻辑；
   - 不获得全知、伤害、防御或额外攻击槽。

2) Bully / 挑衅者、骚扰发起者
   - 更容易主动发起 Observe / Probe / FakeDive / Circle 等普通骚扰；
   - 主要是“更爱找事”，不是更高伤害职业；
   - 必须继续受 AttackSlots=2 硬限制；
   - 不得提高 Extreme Vengeance 伤害或资格；
   - 玩家反杀、Peach、PTSD、DeathShock 等仍然正常压过 Bully 行为。

3) Opportunist / 机会主义观察者
   - 不轻易第一个冲入危险；
   - 更愿意在中距离观察局势；
   - 当真实危险下降后，比普通个体更早回到活动区域；
   - 允许在已有 Fear / CorpseWarning 等危险提示真正降低后，较早重新接近刚发生过事件的区域；
   - 当前不实现主动找尸体/捡资源，未来与第 10 项 Corpse Ecology 接口。

明确不是正式职业：
- Follower-like：主要由现有 Conformity 自然表现，不建立 FollowerRole；
- Loner-like：主要由低 Conformity / 低 RoostAffinity 等自然表现，不建立 LonerRole。

角色表达方式：
- 允许内部计算 Sentinel/Bully/Opportunist tendency；
- tendency 只是权重，不代表拥有职业；
- 只有最高倾向明显超过阈值，并且明显高于第二高倾向时，才允许出现显性角色；
- 如果几个倾向都差不多，即使都不低，也应保持 None；
- 显性角色是 runtime expression，不是出生永久标签，不建议写入存档；
- 危险、PTSD、Grief、Extreme Vengeance、被抓、Shortcut、恶劣天气撤离等可以立即压制角色表达。

稀疏化：
- 可以采用 soft role budget 控制整个群落显性角色总量；
- 软预算只提高后续显性化门槛，不得为了填坑强制把低分个体分配成角色；
- 极端高分个体可以偶尔越过软预算；
- 禁止 MaxSentinel=1 / 每群固定1个Bully 等岗位分配逻辑。

群体上下文：
- 允许增加低频 FlockSnapshot，例如 Center / AverageVelocity / ActiveCount / PanicRatio / RoostRatio / ExpressedRoleCount；
- room-level 每约 20~40 tick 一次 O(n) 即可；
- 禁止每只 Bat 每帧 O(n) 或 O(n²) 扫描；
- FlockSnapshot 只是社会上下文，禁止把原版 Fly locomotion 改造成完整 Boids。

与其他系统接口：
- SocialBond 与职业独立；低 Conformity/Loner-like 个体仍然可以特别在意 BondTarget；
- Grief 会压低 Bully/Opportunist 等角色表达；
- severe PTSD/Fear 高于全部职业逻辑；
- Extreme Vengeance 与职业完全分离，Bully != True Avenger；
- 第 3 项未来 Social Signal System 可以读取 Sentinel/Bully 等角色倾向，但本任务不提前实现完整信号系统；
- 第 8 项 ThreatStyleMemory 和第 10 项 Corpse Ecology 仍需另行深入讨论，不允许 Task 02 擅自补完。

当前结论：
- 深度讨论已经完成。
- 可执行任务书已建立：src/Creatures/DesertBatfly/Task_02_EmergentSocialRoles.txt。
- Codex 实现后必须重新复盘角色与 PTSD / Grief / SocialBond / AttackSlots / Vengeance / Roost / room transition 的状态冲突。


3. Social Signal System / 群体信号系统
状态：【采纳】

核心方向：
- 沙漠蝠蝇之间可以通过真实可观察动作传播行为意图，而不是只靠隐藏数值。
- 候选信号包括：
  1) Alarm Flutter：危险警报；
  2) Rally Signal：极端复仇 / 集结前信号；
  3) Roost Call：倒挂 / 聚集倾向；
  4) Safe Signal：危险结束、恢复正常活动的社会反馈；
  5) Harass Signal：普通骚扰意图。
- Conformity 决定个体有多容易被这些信号影响，但不能强制复制动作。
- 信号应有视距/距离/时效限制，禁止全房间同步。

当前结论：
- 可以进入后续设计与任务书。


4. Injury & Experience / 伤病与经历后遗症
状态：【采纳】

核心方向：
- 非致死伤害不只是 Stun，还可以留下临时或中期行为后遗症。
- 候选包括：
  - 翅部受伤：最大速度、转向、飞行稳定性下降，更容易低飞/休息/被 Peach 捕获；
  - 重 Stun 后：临时降低胆量与攻击欲；
  - Peach Tongue Survivor：曾被 Peach 舌头抓住但被救下/逃脱后，获得更强 PredatorTrauma 或专门的 TongueAvoidanceMemory；
  - 严重创伤可以影响后续社交和复仇判断。
- 伤病不能让普通轻微受击永久废掉个体，必须有恢复过程。

当前结论：
- 可以进入后续设计与任务书。


5. Lightweight Social Bond + Sex / 轻量社会纽带 + 雄性/雌性
状态：【采纳·部分已敲定】

5A. 已实现（自动回归通过，实机行为待验收）
---------------------------------------

A. Sex / 性别
- Desert Batfly 加入稳定的 Male / Female 个体性别。
- 性别由 EntityID.RandomSeed 稳定决定，同一只个体重新 realization、跨房间、读档后都不能变化。
- 当前目标比例：Male 约 48%，Female 约 52%。
- 性别不能决定 Temperament、Nerve、Conformity、VengeanceAffinity、SandSpitAffinity 等人格轴。
- 允许存在非常凶的 Female、非常胆小的 Male；禁止把“雄性=凶、雌性=胆小”写入 AI。
- 性别只允许形成轻度性二型：
  - Male 倾向身体略瘦、视觉翅长略长、spike/pattern 稍突出；
  - Female 倾向身体略大/略厚、翅面略宽；
  - 二型必须是现有随机外观上的小幅 bias，不能覆盖 Temperament 产生的 Size / Contrast / Pattern 差异。
- 玩家熟悉物种后可以大致辨认，但不要求远距离一眼绝对辨认。

B. SocialBond / 重要同伴纽带
- 每只 Desert Batfly 最多保留 1 个 SocialBondTarget 和 1 个 SocialBondStrength。
- SocialBond 是“我特别在乎某一个具体同类”，与 Conformity 的“我容易受群体影响”完全不同。
- SocialBond 必须是单向记录，可以非对称：A->B 很强，而 B->A 较弱是合法状态。
- 同性、异性都可以形成强 SocialBond；SocialBond 本身不是配偶关系。
- 不建立完整 N×N 关系图，不为每只蝠蝇建立 Dictionary<Creature, Bond>。
- 关系来源包括：
  1) 成功从 Peach 舌头/嘴部救援对方：高强度增益，是最重要来源之一；
  2) 长时间稳定处于同一真实 Fly Chain / 邻近 Roost：非常缓慢积累；
  3) 多次在同一威胁事件中近距离共同逃生：小到中等积累；
  4) 后续其他社会系统可以通过明确 API 增加 Bond，但禁止每帧全房间社交扫描。
- BondStrength 范围固定 0..1，并需要持久化。

C. SocialBond 对现有 AI 的影响
- Bond partner 在附近 Roost/Chain 时，提高自己选择其附近 Roost 的倾向，但不能强制进入 Chain。
- Bond partner 遇险时，提高自己对其事件的注意/响应权重。
- Bond partner 被 Peach 捕获时，可以提高现有 Rescue/Extreme Vengeance 的动机，但严重 Fear/PTSD 仍然拥有更高优先级。
- Bond partner 死亡时，产生比普通同类死亡更强的 Shock / Trauma / Grief。
- Bond 不得绕过：dead / unconscious / held / shortcut / severe Trauma / predator danger / normal physical reachability。
- Bond 不得让普通个体无条件成为 True Avenger。
- 当前不启用“只因为 Bond 很高就绕过 5% True Avenger trait”的特殊 Grief Avenger；如未来要做，必须另行讨论。

D. Grief / 丧失重要同伴
- SocialBondTarget 在自己可感知的死亡/捕食链中真正死亡时，可以进入 Grief。
- Grief 是运行时/中期状态，不等于永久人格变化。
- 目标持续时间约 1200~4000 tick，最终值可由 BondStrength 与 Personality 共同调节。
- Grief 的表现应受 Personality 影响：
  - 高 Temperament / 高 Nerve：更可能表现为愤怒、提高已有复仇动机，但仍受 True Avenger/PTSD 规则约束；
  - 低 Temperament 或低 Nerve：更偏向回避、Roost、减少骚扰；
  - 高 Conformity 不等于高 Bond，不能直接代替关系强度。
- Grief 期间总体降低普通 Harass / Attach 意愿，提高 Roost/独处/恢复倾向。
- 如果杀死 Bond partner 的对象已经让该个体形成严重 PTSD，则 PTSD 必须压过 Grief 复仇冲动。

E. Relationship identity / 持久化
- SocialBondTarget 必须使用稳定的 AbstractCreature / EntityID 身份，禁止存 realized Creature 引用到存档。
- 实现时优先保存完整 EntityID 所需字段，而不是只保存容易冲突的临时对象引用。
- partner 不在当前 realized room 时，Bond 仍然存在，但不应产生任何实时导航/全知定位。
- partner 死亡、被永久销毁或存档中已不存在时，应有安全失效/清理策略，不能造成 NullReference 或永久 runtime state 泄漏。

F. 性能
- SocialBond 只能是固定槽，禁止 N×N 关系图。
- Chain/Roost 关系积累应低频采样或复用已有 Chain/Roost 事件，禁止每 tick 对 11+3 群落做全对全距离检查。
- 共同逃生 Bond 增益可以复用现有 Death/Capture 事件遍历，因为这是低频事件。
- Rescue Bond 增益必须挂在成功救援事件上，不新增扫描。

7. Environmental Group Behavior / 环境与天气群体行为
状态：【采纳】

用户已明确采纳的核心：
- 恶劣天气或危险天气到来前，沙漠蝠蝇会提前回巢和躲避。

设计方向：
- 天气恶化不是瞬间全体消失，而应分阶段改变行为：降低飞行高度、减少骚扰、提高 Roost/Hive 倾向、逐步撤离。
- Conformity 可以影响撤离速度：高 Conformity 更容易跟随先行撤离的同伴。
- 高 Nerve / 低 Conformity 个体可以晚一些撤离，但最终仍应尊重真正危险天气。
- HeatWave 等沙漠天气可进一步影响活动高度、飞行消耗和躲避阴影/庇护区域的倾向。

当前结论：
- 可以进入任务书。
- “提前回巢和躲避”是硬要求。


8. Threat Style Memory / 玩家战斗风格学习
状态：【采纳·待深入讨论】

已采纳方向：
- Desert Batfly 可以根据某个具体玩家最近的战斗方式形成有限、可解释的 ThreatStyleMemory。
- 不是机器学习，而是少量稳定统计/记忆。

候选记忆：
- Spear-heavy：玩家频繁用矛击杀/投掷；
- Rock-heavy：玩家频繁用石头击晕；
- Passive/Fleeing：玩家长期只躲避；
- Counter-killer：玩家经常反杀攻击者；
- 未来可考虑其他明显武器/行为类型。

候选行为反馈：
- Spear-heavy：加大 Circle 半径、减少长直线 Dive、看到举矛/投矛准备时更早横向规避；
- Rock-heavy：增加短时规避和高度变化，但死亡威慑弱于 Spear；
- 玩家长期逃跑：恶劣个体的骚扰信心提高；
- 玩家连续反杀：降低靠近意愿，和现有 Trauma / Intimidation 协同。

必须深入讨论：
- 记忆是个体级还是群体可传播；
- 统计时间窗；
- 每类记忆如何衰减；
- 玩家具体动作识别到什么粒度；
- 是否读取玩家手持武器作为即时提示；
- 如何避免“读输入/作弊式预判”；
- 与 PTSD、GrabMemory、Conformity、Extreme Vengeance 的优先级；
- co-op 中必须绑定具体 Player；
- 不应让蝠蝇获得不合理的全知信息。

当前结论：
- 方向已经采纳。
- 必须深度讨论后再写最终任务书。


9. Colony Migration Pressure / 群落迁移
状态：【采纳】

核心方向：
- 如果某个 DESERTSWARMROOM 长期处于高死亡率、Peach 长期驻留、环境持续恶劣等状态，部分沙漠蝠蝇可以迁往相邻适合的群落房间。
- 目标是让群落数量和区域生态出现动态变化，而不是永远固定从同一 Hive 补满。
- 该机制会涉及 AbstractCreature / world population，必须和 realized AI 分层，不能每帧做跨房间扫描。
- 应存在迁移门槛、冷却和容量限制，避免人口在相邻房间之间来回抖动。

当前结论：
- 方向采纳，可以进入后续任务书设计。


10. Corpse Ecology / 尸体生态
状态：【采纳·待深入讨论】

已采纳方向：
- Desert Batfly 尸体不只是 Peach 的食物，也可以成为生态信息源和其他生物的资源。
- 已有基础：Peach 可以捡完整尸体或玩家吃剩但仍有 bites 的残骸并带回巢穴。

候选扩展：
- 尸体对活 Desert Batfly 形成弱 danger cue；
- 高 Conformity 个体更容易避开近期死亡点；
- 多具尸体可形成短期高危险区域；
- 某些 Scavenger / Predator 可能被尸体吸引；
- 尸体来源（玩家 / Peach / 其他捕食者）可能影响活体的风险判断；
- 尸体不应形成永久恐惧场，也不应每帧做全房间昂贵扫描。

必须深入讨论：
- 哪些生物会被尸体吸引；
- 是否做腐败 / 新鲜度；
